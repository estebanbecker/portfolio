# Cybersecurity & Network Engineer Portfolio

A professional portfolio website showcasing expertise in cybersecurity and network engineering. This website is designed to be hosted on GitHub Pages.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Professional Sections**: About, Skills, Experience, Projects, and Contact
- **Modern UI**: Clean, cybersecurity-themed design with smooth animations
- **Easy to Customize**: Simple HTML and CSS structure for quick updates

## 📋 Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Personal introduction and professional background
- **Skills**: Comprehensive display of technical skills in:
  - Cybersecurity (Penetration Testing, SIEM, Incident Response, etc.)
  - Network Engineering (Routing & Switching, Firewalls, VPNs, etc.)
  - Tools & Technologies (Wireshark, Metasploit, Splunk, Python, etc.)
  - Certifications (CISSP, CEH, CCNA, Security+, etc.)
- **Experience**: Professional timeline with detailed responsibilities
- **Projects**: Featured projects with tags and descriptions
- **Contact**: Links to connect via Email, LinkedIn, and GitHub

## 🛠️ Technologies Used

- HTML5
- CSS3
- Modern responsive design principles

## 📦 Getting Started

1. Clone this repository
2. Open `index.html` in a web browser to view locally
3. Customize the content in `index.html` with your own information
4. Adjust styling in `style.css` if desired

## 🌐 GitHub Pages Deployment

This portfolio is ready for GitHub Pages deployment:

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select the branch to deploy (usually `main` or `master`)
4. Select root folder as the source
5. Save and wait for deployment

Your site will be available at: `https://estebanbecker.github.io/portfolio/`

## 📝 Customization

To personalize this portfolio:

1. Update personal information in `index.html`
2. Replace skills, experience, and projects with your own
3. Update contact links with your actual profiles
4. Modify colors in `style.css` (`:root` section) to match your brand
5. Add your own projects and achievements
